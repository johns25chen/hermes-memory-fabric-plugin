# Civilization Core R2 Product Direction and MVP Decision

## Purpose

This document records the bounded product direction and MVP decision
after POST-IDG roadmap activation.

R2 does not authorize implementation.

---

## Primary Product Direction

CIVILIZATION_CORE_GOVERNED_MEMORY_CONTROL_PLANE

Rationale:

The first product direction focuses on governed memory operations:
source tracking, evidence attachment, human review, approval boundaries,
scoped adoption, correction, revocation, and auditability.

---

## Target Users

AI Agent builders and advanced operators requiring governed memory workflows

Secondary future users:

TEAM_MEMORY_USERS

Enterprise deployment is not included in MVP scope.

---

## MVP Core Workflows

Memory Candidate Creation

Evidence Attachment

Human Review Decision

Scoped Memory Adoption

Correction Revoke Delete Lifecycle

---

## MVP Required Capabilities

- provenance tracking
- evidence attachment
- human approval state
- memory lifecycle state
- audit history

---

## Non Goals

- autonomous memory approval
- autonomous execution
- unrestricted agent memory write
- enterprise multi-tenancy
- production deployment
- public release
- v7 runtime

---

## Success Metrics

- approved memory traceability maintained
- rejected memory identifiable
- revoked memory remains auditable
- operator understands memory origin and state
- governance overhead remains acceptable
